

# [Trial.cards](https://trial.cards) 💳

Bienvenido a [trial.cards](https://trial.cards), una aplicación web diseñada para ayudarte a navegar por las pruebas gratuitas sin la preocupación de cargos inesperados. Nuestro servicio genera tarjetas de crédito virtuales temporales (VCC) bajo demanda, sin necesidad de registro o verificación KYC. 🎉

## Características principales 🔍

- Generación instantánea de VCC
- Sin proceso de registro o KYC
- Compatible con múltiples sitios web y servicios
- Interfaz fácil de usar construida con Elm
- Protección contra cargos no deseados por pruebas gratuitas

## Cómo funciona ✨

1. Selecciona el sitio web o servicio deseado
2. Proporciona información personal básica (nombre y código postal)
3. Revisa y acepta los Términos de Servicio
4. Recibe una tarjeta de crédito virtual personalizada para tu servicio seleccionado

## Seguridad y privacidad 🔒

- No almacenamos datos de usuario
- Las VCC son temporales y se generan bajo demanda
- Nuestros Términos de Servicio describen claramente las responsabilidades del usuario y las limitaciones del servicio

## Descargo de responsabilidad ⚖️

Trial.cards se proporciona "tal cual" sin garantías. Los usuarios son responsables de garantizar el cumplimiento de las leyes aplicables y los términos de servicio de los sitios web donde se utilicen las VCC.
